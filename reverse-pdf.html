    About Reverse Pages

    Use this tool to reverse PDF pages when a stack was scanned face down and the document came out back to front. Reverse Pages flips the whole document so the last page becomes the first and the first becomes the last. It takes one click.

    Scanned a stack upside down and ended up with pages in reverse? One click puts them right.

    How to use Reverse Pages

    1. Choose your PDF.
    2. Press Reverse pages.
    3. Download the file with the last page first.

    When to use Reverse Pages

    • Fix a stack of paper that went through a feeder back to front.
    • Read a right-to-left document in the order you need.
    • Prepare pages for printing in reverse order.
    • Correct an export from an app that wrote pages backwards.

    Tips for better results

    • If only part of the file is backwards, use Reorder Pages and type the exact order.
    • Reversing does not rotate pages. Use Rotate PDF if they are also upside down.
    • Check the first page of the result before sharing the file.

    Why use 40PDF for this?

    Reversing is instant because only the page sequence changes. Nothing is re-compressed and nothing leaves your device.

    Reverse Pages: questions and answers

    Does it change the pages themselves?

    No. Only the order changes.

    Can I reverse just a few pages?

    Use Reorder Pages if you want full control.

    How do I reverse the order of pages in a PDF?

    Open Reverse Pages, add your PDF and press Reverse pages. Download the new file with the order flipped.

    Does it change what the pages look like?

    No. Each page is copied as it is. Only the order is different.

    Can I reverse only some pages?

    Not with this tool. Use Reorder Pages to write a custom order for the pages you want to change.

    Reverse Pages: popular searches answered

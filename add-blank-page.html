    About Add Blank Page

    Add Blank Page inserts an empty page wherever you need one. The new page matches the size of the page next to it, so your document keeps a consistent look.

    Useful for adding space for notes, separating sections, or fixing double-sided printing. The blank page matches the size of the page next to it.

    How to use Add Blank Page

    1. Choose your PDF.
    2. Type the page number to insert the blank page after.
    3. Press Add blank page and download.

    When to use Add Blank Page

    • Leave space for handwritten notes between slides or sections.
    • Fix double-sided printing so each chapter starts on a right-hand page.
    • Separate parts of a combined document with an empty divider.
    • Create a spare page for a signature or stamp.

    Tips for better results

    • Type 0 to insert a blank page at the very start of the document.
    • For several blank pages, run the tool again on the new file.
    • Add page numbers last so blank pages are numbered like the rest.

    Why use 40PDF for this?

    The blank page is created inside your browser and matched to your document. You do not need an account or a desktop editor for a task that should take seconds.

    Add Blank Page: questions and answers

    How do I add a page at the start?

    Type 0 in the box.

    What size is the new page?

    The same size as the neighbouring page.

    How do I add a blank page to a PDF?

    Open Add Blank Page, add your PDF, enter the page after which the blank page should appear and press Add blank page.

    Can I add a page at the beginning?

    Yes. Enter 0 in Insert after page, and the blank page goes to the front.

    What size is the new page?

    It copies the size of the neighbouring page, so A4 stays A4 and Letter stays Letter.

    About Reorder Pages

    Use this tool to reorder PDF pages and rearrange a document by typing the order you want. The tool lists the current sequence for you, you change the numbers, and it rebuilds the file page by page in the new order.

    Slides in the wrong order? A scanned contract where page 2 came out last? Type the order you want and Reorder Pages rebuilds the file for you.

    How to use Reorder Pages

    1. Choose your PDF. The current page order appears in the box.
    2. Change the order of the numbers. For example 3, 1, 2 puts page 3 first.
    3. Press Reorder pages and download the result.

    When to use Reorder Pages

    • Fix a scanned contract where page 2 came out last.
    • Move the summary slide to the front of an exported presentation.
    • Put pages of a form back in the order the recipient expects.
    • Bring appendices next to the sections they belong to.

    Tips for better results

    • Write the full sequence, using every page number exactly once, for example 3, 1, 2, 4, 5.
    • To flip the entire document, Reverse Pages is a one-click shortcut.
    • After reordering, add page numbers so references like page 4 make sense to everyone.

    Why use 40PDF for this?

    No drag-and-drop thumbnails to load and nothing to upload. You type the order, the browser rebuilds the file, and big documents stay fast because only text is being edited, not previews.

    Reorder Pages: questions and answers

    Do I have to list every page?

    Yes, each page once. It keeps things safe, so no page goes missing by accident.

    Can I use it to delete a page?

    Not here. Use Remove Pages for that.

    Does it work on big files?

    Yes. Very large files may take a little longer because they are processed on your device.

    How do I rearrange pages in a PDF?

    Open Reorder Pages, add your file, edit the number sequence to the order you want and press Reorder pages.

    Can I delete pages with this tool?

    No. Every page must appear in the new order exactly once. To delete pages, use Remove Pages first and then reorder the result.

    Will links and bookmarks still work?

    Page content is kept, but bookmarks and internal links may point to the old page positions after reordering.

How to Add Page Numbers to a PDF

How-to3 min read2026-08-05

Add page numbers to a PDF in a minute. Choose the position, style like Page 1 of 10 and your start number. Free and private.

Quick summary

  • Choose left, centre or right, and a style such as 1, Page 1 or Page 1 of 10.
  • Numbering should be the last step, after merging, removing and reordering.
  • You can start counting from any number to continue a larger document.

Reports, theses, manuals and scanned bundles look more professional with page numbers, and they make it much easier to say see page 12. With Add Page Numbers you can add them in seconds.

Steps

  1. Open Add Page Numbers and add your PDF.
  2. Pick the position: bottom left, centre or right.
  3. Choose a style: 1, 2, 3, Page 1 or Page 1 of 10.
  4. Set the number to start counting at, if it is not 1.
  5. Press Add page numbers and download the result.

Which style should I use?

Plain numbers look clean in reports. Page 1 of 10 is handy for documents that may be printed, because readers can see immediately if a page is missing. Bottom centre is the classic position, and bottom right suits double-sided printing.

Do it in the right order

Numbers are written onto the page, so change the pages first:

  1. Combine documents with Merge PDF.
  2. Delete pages you do not want with Remove Pages.
  3. Fix the sequence with Reorder Pages.
  4. Add the numbers last.

Continuing from another document

If your file is part two of a longer document, set Start counting at to the next number. A file that begins at page 25 simply starts at 25.

What if the page edge is tight?

Numbers sit near the bottom edge. If a scan has very small margins, trim it first with Crop PDF or check the result before sending it.

Privacy

The numbering is done inside your browser. Your document stays on your device.

Frequently asked questions

How do I number pages in a PDF?

Open Add Page Numbers, add your file, choose position, style and start number and press Add page numbers.

Can I start from a number other than 1?

Yes. Type the starting number in the Start counting at box.

Can I skip the cover page?

Not directly. Split off the cover, number the rest with a start value, and merge them again.

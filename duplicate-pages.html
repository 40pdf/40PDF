    About Duplicate Pages

    Duplicate Pages makes extra copies of the pages you pick and adds them inside the same PDF. It is handy for forms, worksheets and certificates where you need the same page more than once.

    Need extra copies of a form page or a worksheet inside the same file? Duplicate Pages adds them to the end, and you can move them anywhere afterwards with Reorder Pages.

    How to use Duplicate Pages

    1. Choose your PDF.
    2. Type the pages you want to copy.
    3. Press Duplicate pages. The copies are added at the end.

    When to use Duplicate Pages

    • Repeat a blank worksheet page for each student.
    • Make several copies of a form page that must be filled in separately.
    • Create a template with the same layout used many times.
    • Prepare a handout that needs the same cover repeated per section.

    Tips for better results

    • Copies are added at the end of the file. Use Reorder Pages to move them where you want.
    • Need more than one extra copy of a page? Run the tool again on the new file.
    • Your original file is never changed, because a new PDF is created.

    Why use 40PDF for this?

    Copying pages locally keeps templates and forms private. It is also fast since only page references are duplicated, not extra heavy data.

    Duplicate Pages: questions and answers

    Where do the copies go?

    At the end of the document, in the order you listed them.

    Is my original changed?

    No. You get a new file.

    How do I duplicate a page in a PDF?

    Open Duplicate Pages, add your file, type the page number to copy and press Duplicate pages. The copy is added to the end of the new PDF.

    Where do the duplicated pages appear?

    At the end of the document. You can move them afterwards with Reorder Pages.

    Does duplicating pages make the file much bigger?

    Only slightly, since shared content such as fonts is reused.

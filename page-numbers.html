    About Add Page Numbers

    Add Page Numbers prints a number at the bottom of every page. Choose the left, centre or right, pick a style such as Page 1 of 10 and start the count from any number.

    Reports, theses, and scanned bundles all look more professional with page numbers. You can start the count from any number, which is handy when your file is part of a bigger document.

    How to use Add Page Numbers

    1. Choose your PDF.
    2. Pick where the numbers go and the style you like.
    3. Press Add page numbers and download.

    When to use Add Page Numbers

    • Make a thesis, report or manual easier to navigate and quote.
    • Number a bundle of scanned pages in the order they were merged.
    • Continue numbering from a previous part of a larger document.
    • Prepare court, school or office documents where page references matter.

    Tips for better results

    • Merge, remove and reorder pages first, then add numbers as the last step.
    • Use Start counting at to continue numbering from an earlier part of a larger document.
    • Numbers are placed near the bottom edge. Crop PDF first if margins are very tight.

    Why use 40PDF for this?

    Numbering runs entirely in your browser. A confidential thesis or legal bundle gets its page numbers without leaving your computer.

    Add Page Numbers: questions and answers

    Can I skip the cover page?

    Split the cover off first, number the rest, then merge them back.

    Will it cover existing text?

    Numbers sit about a third of an inch from the bottom edge, which is usually clear.

    How do I add page numbers to a PDF?

    Open Add Page Numbers, add your file, choose position, style and start number and press Add page numbers.

    Can I start numbering from a different page number?

    Yes. Type the number you want in Start counting at, and the first page will use it.

    Can I skip the cover page?

    Not directly. A workaround is to split off the cover, number the rest with a start value and merge them again.
